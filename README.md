# 浆料备料测算助手

现场监测员用的「料浆备料测算」工具。原料间通常只给一次基础料浆（往往不够），监测员在一段生产区间抽样记录「区间结束时剩余量」，系统按 **用量 = 基础料浆 − 剩余** 自动算出每车实际均值，再推算还要后补多少料浆，并一键生成补料申请。

**一项目可同时监控多种浆料（最多 12 种）**：生产按「车」计，一辆车会同时消耗多种浆料，所以「项目总计划 / 已生产」是项目级共享的，每种浆料各自记抽样、各自算后补，最后汇总成一份补料申请。

> 手机测试版（H5）：<https://ad3c6c87da8fcb7eb.bj3.agentos-app.net>

## 适用范围

- 产品按「车」计量（一车一个生产单元）。
- 料浆按「升(L)」计量：基础料浆、抽样区间结束剩余、现场实际剩余、后补量，单位都是升。
- 即算即清，不保存历史记录。

## 核心算法

1. **单车实际用量（L/车）** = 各抽样区间「(基础料浆 − 区间结束剩余)(L)」之和 ÷ 涉及车数之和
   - 抽样按「区间」记：第 `start`~`end` 车，区间结束时剩 `remain` 升。系统按 **用量 = 基础料浆 − remain** 算出，车数 = `end − start + 1`。
   - 可记多条区间，系统合并成综合均值；样本车数越多，均值越准。
   - 区间是「区间结束剩余」，不是单车。例如「第2~4车结束时剩0.5L」表示这3车从基础料浆用掉到剩0.5L（用量 = 基础料浆 − 0.5）。
2. **理论剩余（L）** = 基础料浆 − 已生产车数 × 单车实际用量
3. **误差监控（L）** = 现场实际剩余 − 理论剩余（仅填了“现场实际剩余”才显示）
   - 正值：料浆有富余；负值：有损耗或需核查。
4. **后补料浆（L）**（“现场实际剩余”为选填，两种算法自动切换）：
   - **填了实际剩余**：`(总计划 − 已生产) × 单车用料 − 实际剩余` —— 按真实剩余兜底，最准。
   - **没填实际剩余**：`总计划 × 单车用料 − 基础料浆` —— 纯理论值，并跳过误差监控。
   - 大于 0：需后补这么多；小于等于 0：当前料浆可覆盖剩余生产，无需补。

## 一个项目下监控多种浆料

- 一个项目卡片内，顶部是横向滚动的**圆形号码球**标签栏：点「+」添加浆料（最多 12 种）；**点球切换**查看对应浆料；**双击球或长按球弹出菜单**可改名、删除浆料。每种浆料各自填：基础料浆、抽样记录、现场实际剩余（选填），各自独立算出单车用量、误差监控、后补料浆。
- 每个浆料是一个**圆形号码球**（像双色球），球内是浆料编号，球色表示状态：🔴 红 = 不够（需后补，球下显示缺多少 L）｜🟢 绿 = 够用（球下显示「够」）｜⚪ 灰 = 待计算（数据未填全，球下显示「待算」）。扫一眼就知道哪个浆料该申请补料。右上角按钮可切换**白天 / 黑夜模式**，选择会记住。
- 「项目总计划（车）」和「已生产（车）」是**项目级共享**的——生产按车走，所有浆料共用同一套车数。
- 自动已生产车数 = 取**所有浆料抽样区间里**最大的结束车号。
- 卡片底部是**吸底操作条**：左边显「合计后补料浆」= 所有浆料后补量之和；右边「生成补料申请」会把每种浆料明细 + 合计一起复制到剪贴板。

## 已生产车数：手动 / 自动切换

每个项目卡片有「手动输入已生产（车）」开关：

- **默认关闭（自动）**：系统取「所有浆料抽样区间里最大的结束车号」作为已生产车数。
  因为大多数抽检从第1车开始，抽检最大车号基本就等于已生产车数，省得重复填。卡片上显示为「已生产（车·自动）」。
- **打开开关（手动）**：出现「已生产（车）」输入框，自己填。
  适合这两种情况：
  1. 抽检不是从第1车开始（如第2车才记），自动值偏小，需手动填准确值；
  2. 想手动覆盖自动值（已知确切已生产车数）。

在「生成补料申请」里，自动模式下已生产会标注「（自动）」。

## 微信小程序使用

1. 电脑安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开工具 → 导入项目 → 选择本目录 `浆料备料测算助手/`。
3. AppID 可用「测试号」或你自己的。
4. 编译后预览；可扫码在手机上真机调试。

目录结构：

```
浆料备料测算助手/
├── app.js / app.json / app.wxss      # 全局配置与样式
├── project.config.json               # 项目配置
```

## 字段速查

| 字段 | 单位 | 说明 |
|------|------|------|
| 项目总计划 | 车 | 项目级。本批要生产的总车数（目标），所有浆料共用 |
| 已生产 | 车 | 项目级。默认自动取所有浆料抽检最大车号；可手动覆盖 |
| 几号浆料（圆形球编号） | — | 每种浆料的名称/编号（如“1号浆料”）。**双击圆球或长按球弹出菜单**可改名；长按菜单可删除 |
| 基础料浆 | L | 该浆料：原料间这次给的基础料浆量 |
| 抽样区间·起/止 | 车 | 该浆料：抽样从第几车到第几车 |
| 抽样区间·区间结束剩余 | L | 该浆料：该区间**结束时**容器里还剩多少升（直接看得到的）。系统按 用量 = 基础料浆 − 剩余 自动算，无需手算 |
| 现场实际剩余 | L | 该浆料：选填。实测容器里还剩多少料浆；不填则后补量按纯理论算 |
| 后补料浆 | L | 计算结论：该浆料还需向原料间要多少升 |
| 合计后补料浆 | L | 项目级：所有浆料后补量之和 |
